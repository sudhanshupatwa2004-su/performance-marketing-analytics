# WishCare-Inspired Performance Marketing Analytics & Campaign Optimisation

An end-to-end performance marketing analytics project for a beauty and personal-care e-commerce brand, built with
**Excel, SQL, Python and Power BI**.

> **Simulated data.** Every number comes from a synthetic dataset generated by `scripts/01_generate_data.py`.
> The project is inspired by a D2C beauty brand like WishCare, but it does **not** represent WishCare's real
> campaign performance.

## Key results (60 days, 14 campaigns)
| Ad Spend | Revenue | Orders | New Customers | ROAS | CAC | CTR | CPC | CPM | CVR | AOV |
|---|---|---|---|---|---|---|---|---|---|---|
| ₹33.16 L | ₹72.67 L | 12,359 | 7,576 | 2.19x | ₹438 | 1.29% | ₹11.39 | ₹146.92 | 4.25% | ₹588 |

- Google Ads: 35% of spend → 50% of revenue (ROAS 3.13x).
- Blended ROAS falls from 2.19x to **1.76x** without brand search.
- Generic hair-fall search is the best growth engine (CAC ₹237, 84% new customers). It is the only campaign recommended for a scale test.
- The Vitamin C influencer video is fatiguing (CTR −24%).
- A/B test: the UGC video won on CTR (+15.9%, p < 0.001) but **not** on conversion or ROAS.

## Suggested learning path (beginner)
1. Read `docs/01_Executive_Summary.md` to understand the story first.
2. Open the **notebook** and read it top to bottom. Every step explains *what* it does and *why*.
3. Open the **Excel workbook** and click into the formulas on `KPI_Summary`, `Campaign_Analysis` and
   `Budget_Optimisation`. Change a yellow cell on `Assumptions` and watch the decisions update.
4. Run the **SQL** file in MySQL Workbench (Section 0 loads the CSVs) and compare the results with Excel.
5. Build the **Power BI** dashboard with `powerbi/Power_BI_Dashboard_Build_Guide.md`, then check your cards against the expected values.
6. Practise `docs/03_Interview_Questions_and_Answers.md` out loud, and present using the interview deck.

The fixed random seed means you get exactly the same numbers every time.

## Consistency guarantee
Every KPI is calculated as **SUM(numerator) ÷ SUM(denominator)**, with zero-denominator guards
(`IF(...=0,"",...)` in Excel, `NULLIF` in SQL, `DIVIDE` in DAX, NaN in Python). The Excel `Checks` sheet
shows each Excel KPI matching the Python value, and `scripts/test_sql.py` checks SQL against Python.

## Assumptions (not data)
Contribution margin before ads: 55% for website sales, 40% for marketplace sales (break-even ROAS 1.82x / 2.50x). Target CAC ₹450.
Scaling assumption: extra spend earns 70% of current ROAS. You can edit all of these on the Excel `Assumptions` sheet.
